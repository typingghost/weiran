# 未然

道德经八十一章的手机阅读页，配六期播客，可以离线收听。

- 打开：<https://typingghost.github.io/weiran/>
- 首页默认写"亲爱的你们，今天读第几章"，大家共用一个链接就行。想换称呼，可以在链接后面加 `?to=称呼`。
- 高配版：链接加 `?hq=1`，播客换成 96k 高音质，字体用在线书法字体（需要能打开 Google Fonts）。
- 首页底部"全部存到本机"可以一次把六期都下载好，之后断网也能听。第一次打开时的称呼和高配设置会记在这台设备上。
- 在 iPhone 或 iPad 上，用 Safari 打开以后点"分享"→"添加到主屏幕"，就会像一个 App 一样出现在桌面上。
- 每一期播客第一次播放时会在后台整段存下来，之后断网也能听。

原本是给家人做的安卓离线 App，这是同一份内容的网页版。由深海基地全员制作。
